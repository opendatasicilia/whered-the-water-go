Esempio di pagina che incorpora la mappa

Qui sotto la mappa è inserita con un semplice <iframe>. L'altezza si adatta da sola grazie a un piccolo script (vedi sorgente di questa pagina).

Quando la ospiterai su GitHub Pages, sostituisci l'attributo src con l'URL pubblico del file, per esempio
src="https://tuo-utente.github.io/tuo-repo/precipitazione-annua-sicilia.html".
